Generated by `python -m src.modeling.phase5_report`. Every performance number comes from a chronological backtest in which training used only outcomes observable at the forecast date. **All are exploratory estimates from small samples, not validated generalization accuracy.** The 2019-2021 classes have been examined repeatedly across phases.

## Key findings

* **Draft status is much more predictable than NFL success.** College production plus Combine attendance separate drafted from undrafted fourth- and fifth-year QBs well. Projecting the round and the NFL career is much harder.
* **Draft position carries most of the forecastable signal about NFL opportunity.** Adding the actual pick cuts five-season games-started MAE from 20.2 to 14.9, and every statistic improves, with intervals excluding zero. Part of this is causal: high picks are given starts. So it is not evidence that teams evaluate better than college data in every sense.
* **Structured vs direct forecasting:** the structured simulation produces coherent, consistent stat lines, year-by-year paths and conservative intervals. It does **not** beat direct models on point accuracy. Direct logistic models give the better starter probabilities.
* **Efficiency (YPA, completion %, TD/INT rates) is essentially unpredictable** from college data at this sample size.
* **Comps explain; they do not forecast better.** The 10-nearest-comp success rate is weaker than the logistic model.

## Data that is unavailable locally

* **Draft declarations:** there is no source for which underclassmen declared. Undrafted early entrants cannot be identified, so draft probability is limited to the verified universe.
* **Recruiting class links:** CFBD athlete ids are sparse before about 2011. Seasons observed in the data stand in where possible.
* **College data for some drafted QBs:** pre-2004 final seasons, and FCS final seasons before 2022 (Flacco, Wentz, Garoppolo and others).
* **Pre-draft scouting ranks and all-star games:** CFBD rankings exist only for drafted players, so they are excluded.
* **Detailed play-by-play** (passer-level, 2004-2015) is deferred until the CFBD quota resets. No API calls were made in this phase.

## Reproduce


## Recommended next phase

1. **Prospect universe:** add declaration/early-entrant and transfer-portal data, so draft probability covers underclassmen.
2. **Calibration:** recalibrate the round model (shrink it toward base rates) and the simulation's intervals (scale its residual draws), using nested backtests.
3. **Uncertainty:** after the Dec 1 quota reset, fetch passer-level 2004-2015 play-by-play, so play-type features can be tested on 180+ QBs. The 2026 class can serve as a genuinely prospective test as its NFL seasons arrive.
4. **Frontend:** only after the above, a dashboard over `forecast_prospect`.
